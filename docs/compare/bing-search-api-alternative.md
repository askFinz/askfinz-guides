## Key points

### What the Bing Search API was

A straightforward call-in, results-out API: send a query, get back a page of ranked web results, ads and related data to render or process yourself.

### What askFinz is

askFinz runs its own crawled web index, read continuously rather than fetched per query.

### What the retirement actually taught

The retirement removed the budget option most of this market was standing on, and it did so on Microsoft's timetable rather than anyone else's.

### Be honest about the migration you are actually doing

Treat this as an architecture decision, not a find-and-replace on an API key. The products filling this gap are not identical to what was retired, and they are not identical to each other.

## Frequently asked

### When was the Bing Search API retired?

11 August 2025.

### What does Microsoft's replacement cost?

Microsoft publishes more than one figure for it, and no single number is quoted here for that reason. Check Microsoft's own pricing page.

### What does askFinz cost?

$0.75 as a top-up, $1.00 with the extension, $3.50 standalone, per 1,000 searches, as published on pricing.

### Does askFinz depend on Bing or Google underneath?

No. It reads and holds its own index and does not query another engine.
