Yes. Claude is one of several leading model families available; see which models are available.

### Is askFinz built by Anthropic?

No. It is an independent product that makes several providers' models available in one workspace.

### Does claude.ai have its own web index?

No — claude.ai searches the web at the moment you ask. askFinz reads and holds its own, ahead of the question, which is what Search runs on: an answer arrives with the passage and the address it was read from, out of an index filed by document type rather than kept as loose pages.

### Do I have to give up Claude to use askFinz?
