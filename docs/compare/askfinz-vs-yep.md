### Yep vs askFinz

### A sentence is not an argument

Yep returns the sentence that matched, which is a genuinely useful thing to have — it tells you why a result is in the list, which a ranked link on its own never does.

### Independence is worth saying out loud

Yep runs its own crawler and index rather than relaying somebody else's results. That puts it in the same group as askFinz and a long way from the rows in our table that pass a query to a search engine and hand back what came out.

### Where Yep is the better buy

If you want an independent index behind a simple search endpoint and the matching sentence is enough context for your application, Yep is a reasonable fit — and it is cheaper than most of the model-hosted web search tools in the same table.

### What askFinz does that an endpoint cannot

The same index answers in askFinz Search, is read by the workspaces, and reaches the browser through the extension — so what you are pricing is also a product people work in.
