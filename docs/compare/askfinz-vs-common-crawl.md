## Key points

### What Common Crawl is

Common Crawl publishes large, periodic snapshots of the web as raw WARC, WAT and WET files, freely available for anyone to download and process.

### What askFinz is

askFinz does not publish dumps.

### Two gaps: age, and shape

A Common Crawl archive tells you what the web looked like on the day it was captured. That is exactly right for research and exactly wrong for a question about something that has changed since.

## Frequently asked

### Is Common Crawl free?

Yes, entirely. That is a real advantage and this page does not argue against it.

### How current is a Common Crawl archive?

As current as the crawl that produced it. Between publications, nothing in it moves.

### Can I search Common Crawl directly?

Not without building the index yourself. The archive is raw crawl data; querying it is a project.

### Does askFinz publish a downloadable dataset?

No. It does not sell or publish index access as a standalone feed.

### Which should I use to train a model?

Common Crawl. It is designed for that, it is free, and it is citable. askFinz is not a training corpus.
