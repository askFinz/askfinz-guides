# You.com Search API alternative

**Canonical page:** [https://askfinz.com/compare/askfinz-vs-you-com](https://askfinz.com/compare/askfinz-vs-you-com)

## Key points

### What You.com Search API is

You.com built a consumer AI search engine and, alongside it, a Search API developers can call directly. A query goes in and a configurable set of results comes back — from a single top hit up to 100 in one request.

### What askFinz is

askFinz runs its own crawled web index, read continuously rather than fetched per query.

### Where the two products end

A batch of results is raw material.

### What askFinz gives up in exchange

Control. There is no parameter to set, no result count to tune, no way to ask for a hundred candidates and re-rank them yourself.

## Frequently asked

### Does You.com run its own search index?

Yes. It searches its own index rather than relaying another engine's results page.

### Can I set how many results askFinz returns?

No. Result count is not the unit of the product; the answer and its matched passage are.

### Is 100 results per call useful?

Very, if your application re-ranks or filters. It is exactly the wrong shape if what you wanted was one answer with its source attached.
