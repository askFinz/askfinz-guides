# How AI search actually finds an answer

From your question to a sourced answer — how AI search bridges a live index and a language model to answer in words instead of ten blue links.

**Canonical page:** [https://askfinz.com/guides/how-ai-search-finds-answers](https://askfinz.com/guides/how-ai-search-finds-answers)

## Key points

### It starts with an index, not a live web crawl

The first thing worth clearing up is that AI search doesn't crawl the web fresh every time you ask a question — that would be far too slow. It searches an index that's already been built, continuously, ahead of time.

### Step one: retrieval

When a question comes in, the system doesn't do a keyword match against the index — it searches by meaning.

### Step two: synthesis

Retrieval alone would just be a better list of links — more relevant, but still something you'd have to read yourself.

### Why the sources still matter

A well-built AI search answer isn't asking you to trust it blindly — it's showing its work. Because the answer was composed from specific retrieved passages, those passages can be cited directly, and the trail back to the original page is already there.

### Why this needs a real, current index underneath it

Everything above depends entirely on the index being both broad and current. If the index hasn't read the page that actually answers your question, no amount of clever retrieval or synthesis conjures an answer that isn't there — the system can only work with what it's actually indexed.
